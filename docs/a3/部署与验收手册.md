# A3 部署、启动、验收与故障排查手册

## 1. 环境要求

- Python `3.12`
- Node.js 与 npm
- PostgreSQL
- 可选 Neo4j
- 可选 LLM API Key
- Windows / Linux 均可，本地命令以仓库规则为准

## 2. 后端启动

基于 `backend/.env.example` 创建本地 `backend/.env`，不要提交该文件。

```bash
cd backend
uv sync
uv run python manage.py migrate
uv run python manage.py runserver 127.0.0.1:8000
```

健康检查：

```bash
curl http://127.0.0.1:8000/health/
```

## 3. 前端启动

```bash
cd frontend
npm install
npm run dev
```

默认访问 `http://127.0.0.1:3000`。Vite 会代理 `/api`、`/media`、`/static`、`/ws` 到 `http://127.0.0.1:8000`。

## 4. 数据库迁移

```bash
cd backend
uv run python manage.py migrate
uv run python manage.py check
uv run python manage.py makemigrations --check --dry-run
```

## 5. 样例账号和课程数据

```bash
cd backend
uv run python tools.py create-test-data
uv run python tools.py bootstrap-course-assets --course-name "大数据技术与应用"
```

如需 student1 完整演示快照：

```bash
uv run python tools.py preset-student1-demo-snapshot
```

`pg-bootstrap` 是破坏性初始化命令，会清库并重建样例数据；不要在普通验收中默认运行。

## 6. GraphRAG 索引构建

课程资源、知识点或关系发生变更后：

```bash
cd backend
uv run python tools.py build-rag-index
```

运行产物保存在 `backend/runtime_logs/rag/`，不提交版本库。

## 7. KT 状态检查

```bash
cd backend
uv run python tools.py mefkt-status
```

MEFKT 不可用时，系统使用规则和统计兜底，不阻断 A3 主流程。

## 8. A3 主流程验收

前置条件：

- 后端 `/health/` 正常。
- 前端已启动。
- 学生账号已登录。
- 学生已选中“大数据技术与应用”课程。

点击路径：

1. 打开 `/student/agent-learning`。
2. 输入画像描述和学习目标。
3. 点击“抽取画像”。
4. 点击“生成资源包”。
5. 查看运行轨迹、质量分和 warnings。
6. 打开资源卡片证据抽屉。
7. 点击“应用到学习路径”。
8. 对一张资源提交学习反馈。
9. 查看效果摘要。

## 9. OpenAPI 契约校验

```bash
npx @redocly/cli lint adaptiveedu@v1
npx @redocly/cli bundle adaptiveedu@v1
```

## 10. 前端类型检查和构建

```bash
cd frontend
npm run typecheck
npm run build
```

构建会生成 `frontend/dist/`，该目录不提交。

## 11. 后端测试

Agent 快速测试：

```bash
cd backend
uv run python manage.py test ai_services.tests.student.test_agent_api --verbosity 2
```

AI 服务全量测试：

```bash
uv run python manage.py test ai_services.tests --verbosity 2
```

## 12. 浏览器巡检

后端和前端都启动后：

```bash
cd backend
uv run python tools.py browser-audit --scenario audit --frontend-url http://127.0.0.1:3000 --api-base-url http://127.0.0.1:8000
```

## 13. 常见问题与排查

| 问题 | 排查方式 |
| --- | --- |
| 后端 `.env` 缺失 | 对照 `backend/.env.example` 创建本地文件 |
| PostgreSQL 连接失败 | 检查数据库服务、用户名、密码、库名和端口 |
| Neo4j 不可用 | 可先使用 PostgreSQL 图谱回退，不阻断主流程 |
| GraphRAG 索引缺失 | 执行 `uv run python tools.py build-rag-index` |
| LLM Key 未配置 | Agent 资源生成会使用模板化兜底内容 |
| 前端代理错误 | 检查 `VITE_DEV_BACKEND_ORIGIN` 或默认后端端口 |
| 学生路由跳转课程选择 | 先在 `/student/course-select` 选择课程 |
| OpenAPI lint 失败 | 检查新增路径 `$ref` 和 schema 是否存在 |
| 资源证据为空 | 前端应展示 warnings，不能伪造成课程来源 |
