```bash

uv run python manage.py check
uv run python manage.py makemigrations --check --dry-run
uv run python manage.py test ai_services.tests --verbosity 2

cd ../frontend
npm run typecheck
npm run build

cd ..
npx @redocly/cli lint adaptiveedu@v1
npx @redocly/cli bundle adaptiveedu@v1
```

## 8. 残余风险与待扩展项

- 当前 Agent 主流程为同步接口；长耗时生成可扩展为异步任务或 SSE。
- 视频资源当前生成脚本和分镜，不生成真实视频文件。
- 生成内容目前以模板和规则为主，后续可接入教师审核和更强 LLM 结构化输出。
- GraphRAG 索引需要在课程资源变更后重建。
