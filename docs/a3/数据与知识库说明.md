# 课程知识库、演示数据与资源资产说明

## 1. 课程选择与覆盖范围

A3 主演示课程为“大数据技术与应用”。该课程覆盖大数据基础、Hadoop、HDFS、MapReduce、HBase、Hive、Spark、机器学习、推荐系统和自然语言处理等主题，适合展示知识图谱、初始测评、学习路径、资源生成和反馈闭环。

## 2. 课程资产清单

课程资产位于：

```text
backend/tools/自适应学习系统-课程资源/
```

主要资产：

- `大数据图谱构建.xlsx`：知识点和关系导入来源。
- `大数据知识初始评测.xls`：课程知识初始测评题。
- `PPT/`：章节课件。
- `教学视频/`：课程视频，含 `.mp4` / `.mov`。
- `电子教材/`：PDF 教材。
- `作业库(excel)/`：章节作业题库。

## 3. 知识点与关系建模

知识点模型：`backend/knowledge/models.py` 的 `KnowledgePoint`。

关系模型：`KnowledgeRelation`，支持：

- `prerequisite`：先修关系。
- `part_of`：包含关系。
- `related`：相关关系。
- `includes`：层级包含。

学生端知识图谱和 Agent 证据追溯都读取这些课程知识点和资源关系。

## 4. 题库与测评数据

基础测试数据位于：

```text
backend/tools/testdata.json5
```

课程题库可通过课程资产导入工具写入 `assessments`、`exams` 和 `knowledge` 相关表。初始测评结果会写入知识掌握度，为 MEFKT 和学习路径提供基础观测。

## 5. 课程资源与多媒体资产

课程资源模型：`knowledge.Resource`。资源可以关联多个知识点，并作为以下能力的输入：

- 学生课程资源页。
- 学习路径节点资源。
- Agent 资源生成 evidence。
- GraphRAG 课程语料。

视频、PPT、PDF 等非代码资产不随 AFL-3.0 源代码许可证自动授权；使用前应确认课程材料权利来源。

## 6. GraphRAG 索引构建

GraphRAG 运行产物默认位于：

```text
backend/runtime_logs/rag/
backend/runtime_logs/rag/qdrant/
```

这些是运行时产物，不提交版本库。课程资源或知识图谱发生较大变化后，应重新构建索引：

```bash
cd backend
uv run python tools.py build-rag-index
```

Neo4j 不可用时，学生端知识图谱和部分证据链路会回退到 PostgreSQL 图谱数据。

## 7. MEFKT 训练与推理数据

MEFKT 模型与公开数据基线位于：

```text
backend/models/MEFKT/
```

状态检查：

```bash
cd backend
uv run python tools.py mefkt-status
```

MEFKT 不可用时，KT 服务使用内置统计和规则兜底，不阻断 A3 资源生成主流程。

## 8. 演示账号与样例数据

基础账号、课程、班级和样例关系由以下命令创建：

```bash
cd backend
uv run python tools.py create-test-data
```

演示课程资产导入：

```bash
uv run python tools.py bootstrap-course-assets --course-name "大数据技术与应用"
```

如需补齐 student1 演示快照：

```bash
uv run python tools.py preset-student1-demo-snapshot
```

`pg-bootstrap` 会迁移、清库、创建测试数据并尝试导入课程资产，属于破坏性初始化；除非明确需要重建本地样例库，不作为默认验收命令。

## 9. 数据重建命令

推荐顺序：

```bash
cd backend
uv run python manage.py migrate
uv run python tools.py create-test-data
uv run python tools.py bootstrap-course-assets --course-name "大数据技术与应用"
uv run python tools.py build-rag-index
uv run python tools.py mefkt-status
```

验证数据库状态：

```bash
uv run python tools.py django-check
uv run python tools.py db-check
```

## 10. 授权和非代码资产边界

- 源代码许可证见根目录 `LICENSE`。
- 后端依赖来源为 `backend/pyproject.toml` 和 `backend/uv.lock`。
- 前端依赖来源为 `frontend/package.json` 和 `frontend/package-lock.json`。
- `backend/.env` 不提交；只提交 `backend/.env.example`。
- `backend/runtime_logs/`、`frontend/dist/`、`node_modules/` 不提交。
- 课程资源、多媒体、公开数据集和演示素材应按各自授权边界使用。
