# 多智能体协作与个性化资源生成说明

## 1. 设计目标

A3 Agent 的目标是把学生自然语言目标转换为可执行学习资源包。系统不是直接把 prompt 发给模型，而是先读取学习画像和课程证据，再通过角色化 trace 输出资源、质量报告、路径建议和反馈闭环。

## 2. 多智能体角色定义

| Agent | 职责 | 当前实现 |
| --- | --- | --- |
| `profile_agent` | 抽取学习目标、基础、薄弱点、偏好、节奏等画像字段 | `ProfileDialogService` |
| `knowledge_agent` | 收集课程知识点、已有课程资源和 GraphRAG 证据 | `ResourceGenerationService._collect_evidence` |
| `path_agent` | 给出资源学习顺序和路径节点匹配建议 | `LearningPackageService._build_path_suggestion` |
| `resource_agent` | 生成讲解、导图、练习、阅读、实操等资源 | `ResourceGenerationService` |
| `multimodal_agent` | 生成思维导图和视频脚本等多模态表达 | `resource_generation.py` |
| `evaluation_agent` | 输出质量报告、warnings 和防幻觉提示 | `AgentQualityGuard` |

## 3. 编排流程

1. 校验学生身份和课程权限。
2. 抽取或合并学习画像。
3. 从课程知识点、课程资源和 GraphRAG 资料中收集 evidence。
4. 生成不少于 5 类资源。
5. 质量守卫校验标题、正文、类型、证据和资源特定结构。
6. 输出 `agent_trace` 和 `progress_events`。
7. 可选绑定到学习路径。
8. 收集反馈并形成效果摘要。

## 4. 对话式画像抽取

画像字段定义在 `backend/ai_services/services/agent/schemas.py`：

- `major_or_background`
- `course_goal`
- `knowledge_foundation`
- `weaknesses`
- `preferred_resource`
- `learning_style`
- `pace`
- `available_time`
- `practice_preference`
- `motivation`

示例输入：

```text
我是软件专业学生，想两周内掌握 Spark SQL，但 HDFS 和 MapReduce 基础不太好，喜欢视频和案例。
```

示例输出片段：

```json
{
  "profile": {
    "course_goal": "两周内掌握 Spark SQL",
    "weaknesses": ["HDFS 和 MapReduce 基础不太好"],
    "preferred_resource": ["video", "coding_case"],
    "learning_style": "kinesthetic",
    "pace": "fast"
  },
  "missing_slots": ["available_time"],
  "next_question": "你每天或每周大约可以投入多少学习时间？"
}
```

## 5. 资源生成类型与结构

| 类型 | 内容结构 |
| --- | --- |
| `explanation` | Markdown 讲解文档，包含目标、要点和课程证据 |
| `mindmap` | Mermaid mindmap 与节点列表 |
| `quiz` | 题目、选项、答案、解析和难度 |
| `reading` | 拓展阅读条目、推荐理由和来源类型 |
| `coding_case` | 场景、步骤、示例代码和期望输出 |
| `video_script` | 时长、分镜、旁白和视觉提示 |

第一阶段视频能力生成脚本和分镜，不生成真实视频文件。

## 6. 证据追溯与防幻觉策略

证据优先级：

1. 当前课程知识点。
2. 与知识点关联的课程资源。
3. 课程可见资源。
4. GraphRAG/课程知识库证据。
5. 为空时返回 warnings 并使用模板兜底。

示例：

```json
{
  "evidence": [
    {
      "source_type": "knowledge_point",
      "id": 12,
      "title": "Spark SQL",
      "summary": "Spark SQL 查询与 DataFrame 操作"
    }
  ],
  "warnings": []
}
```

证据为空时：

```json
{
  "evidence": [],
  "warnings": ["未检索到课程知识库证据，已使用模板化兜底内容。"]
}
```

## 7. 学习包与路径绑定

`POST /api/student/agent/learning-package` 生成资源包后，返回 `path_suggestion`。学生确认后调用 `POST /api/student/agent/apply-to-path`：

- 优先匹配相同 `knowledge_point_id` 的未完成节点。
- 找不到节点时插入 `A3 补充` 节点。
- 不删除已完成节点。
- 绑定信息写入 `GeneratedLearningResource.metadata.path_binding`。
- 节点进度写入 `NodeProgress.extra_data.generated_resources`。

## 8. 反馈闭环

资源反馈接口：`POST /api/student/agent/resources/{resource_id}/feedback`。

记录内容：

- 是否完成。
- 1-5 评分。
- 有用性：`useful`、`neutral`、`not_useful`。
- 难度：`easy`、`moderate`、`hard`。
- 文本反馈、练习结果和学习耗时。

反馈会同步到节点进度扩展数据，并由 `GET /api/student/agent/effect-summary` 汇总。

## 9. 失败降级和质量校验

质量守卫检查：

- 标题存在且不超长。
- 正文不为空。
- 资源类型在白名单内。
- 证据为空时给 warning。
- 练习题必须带答案解析。
- 代码案例必须带步骤和代码。
- 思维导图必须带 mermaid 或 nodes。

质量报告示例：

```json
{
  "status": "warning",
  "score": 0.92,
  "resource_count": 5,
  "warnings": ["未检索到课程证据，前端需展示防幻觉提示"],
  "errors": []
}
```

## 10. agent_trace 示例

```json
[
  {"agent": "profile_agent", "status": "completed", "summary": "已抽取学习画像字段"},
  {"agent": "knowledge_agent", "status": "completed", "summary": "已收集 2 条课程证据"},
  {"agent": "path_agent", "status": "completed", "summary": "已生成资源学习顺序建议"},
  {"agent": "resource_agent", "status": "completed", "summary": "已生成 5 类个性化资源"},
  {"agent": "evaluation_agent", "status": "completed", "summary": "已完成质量校验"}
]
```

## 11. 生成资源与推荐已有资源的区别

- 生成资源：写入 `GeneratedLearningResource`，包含正文、结构化 payload、evidence、metadata 和画像快照。
- 推荐已有资源：读取 `knowledge.Resource`，用于课程资源列表、任务学习和证据来源。

生成资源必须能追溯到课程知识库证据；推荐已有资源则直接指向教师维护的课程资源。
