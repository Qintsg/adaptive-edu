# AdaptiveEdu 答辩录屏讲解词

## 开场

大家好，我用“大数据技术与应用”课程展示 AdaptiveEdu 的主要操作。

## 已学习学生

先看第一位学生。学习中心显示他当前的课程和进度。学习画像把测评、习惯和知识点掌握情况放在一起，方便看出短板。知识图谱中可以查看知识点之间的关系，也能打开与课程关联的资料。学习路径把下一步任务排出来；点进任务后，可以阅读资源并记录完成情况。

这里我问 AI 助手：Spark SQL 和 DataFrame 有什么关系？系统给出结合这门课程的回答。接着打开在线作业，可以看到已经提交的作业和反馈报告。这样，从发现薄弱点、学习课程内容到做题和回看反馈，就连成了一条线。

## 新学生初始测评

现在切到第二位学生。他已经加入“大数据技术与应用”，但还没有测评或学习记录。知识测评使用这门课程的五十道初测题，右侧答题卡会同步标出已答题目。我依次作答并提交，系统先给出即时评分，再补齐报告中的知识点分析和建议。接着完成十六道能力评测题，了解阅读、推理和处理信息的情况；最后做九道习惯问卷题，记录学习时间、资源和练习偏好。三项测评完成后，报告汇总当前的知识掌握情况和学习建议。学习画像把这些结果放在一起，学习路径再排出接下来的任务。它和第一位学生的路径不同，因为两个人的起点不同。

## 教师功能

教师账号能查看自己负责的课程和班级。进入大数据课程后，可以看到从原始课程资料导入的知识点、题目和资源。题库与作业按课程组织，教师可以据此安排练习，也可以查看学生的学习情况。

## 管理员功能

最后看管理员。控制台给出系统概览；用户管理能看到两位学生和一位教师，课程与班级页面可以查看教学组织关系。现场完成新学生测评之后，只需运行交付包中的恢复脚本，就能把账号和课程数据恢复到这一版起点，方便下一轮展示。

## 结束

以上是三个角色的操作。谢谢观看。
