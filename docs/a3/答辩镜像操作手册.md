# AdaptiveEdu 答辩镜像操作手册

交付包包含 Docker 镜像、大数据课程资料、四个账号和恢复数据。学生 `student1` 已有学习记录，`student2` 处于加入课程后的未测评状态。

## 启动与恢复

启动 Docker Desktop，在交付目录打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Restore-Demo.ps1 -BundleDirectory .
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Verify-Demo.ps1
```

打开 `http://127.0.0.1:18080`，浏览器使用 1920×1080。恢复脚本会重置 `adaptive-edu-defense-demo` 项目的数据库和课程文件。

日常启动保留当前学习记录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Start-Demo.ps1 -SkipBuild
```

## 账号

| 角色 | 用户名 | 密码 | 展示内容 |
| --- | --- | --- | --- |
| 已学习学生 | `student1` | `Test123456` | 学习画像、知识图谱、路径、任务和作业反馈 |
| 新学生 | `student2` | `Test123456` | 初始测评、画像和学习路径生成 |
| 教师 | `teacher1` | `Test123456` | 课程、题库、资源和班级 |
| 管理员 | `admin` | `Admin123456` | 用户、课程和班级管理 |

## 演示步骤

1. 使用 `student1` 登录，查看“大数据技术与应用”的学习进度。
2. 打开“学习画像”，查看能力、掌握度和学习建议。
3. 打开“知识图谱”，点击知识点查看关联内容。
4. 打开“学习路径”，进入任务，查看学习资源。
5. 打开“AI 助手”，搜索“Spark SQL基本操作”，提问：`Spark SQL 和 DataFrame 有什么关系？`。展示检索状态和正文逐步输出。
6. 打开“在线作业”的已完成列表，查看反馈报告和逐题解析。
7. 切换到 `student2`，完成知识、能力和学习习惯三项测评，查看报告、画像和学习路径。
8. 切换到 `teacher1`，展示课程、资源、题库和班级；切换到 `admin`，展示用户、课程和班级管理。

演示后执行恢复命令，可将两个学生恢复到起点。

## AI 与掌握度

后端镜像内置 DeepSeek API 密钥，问答模型标识为 `deepseek-flash`。在线回答通过 WebSocket 输出。网络不可用时，固定问题使用已核对答案，其他问题使用课程内容。镜像环境变量包含密钥，交付包按账号凭据管理。

当前 CPU 镜像依据历史答题记录计算掌握度，MEFKT 内容编码器未安装。

## 交付文件

| 文件 | 内容 |
| --- | --- |
| `images.tar` | 前端、后端、PostgreSQL、Neo4j 和材料镜像 |

| `media-rag-baseline.tar` | 课程文件与检索索引 |
| `manifest.json` | 源码版本、镜像 ID 和归档 SHA-256 |
| `screenshots/` | 本次页面截图 |
| `recordings/` | 已保存的演示视频，采集版本见随附记录 |

从 Docker 提取手册、截图和视频：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Extract-Artifacts.ps1
```
