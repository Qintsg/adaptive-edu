# AdaptiveEdu 答辩镜像操作手册

这份手册给现场演示者使用。交付包包含可离线载入的 Docker 镜像、数据库起点、课程文件、截图和讲解录屏。恢复脚本会把两名学生重新放回各自的起点：`student1` 已有学习记录，`student2` 只加入了“大数据技术与应用”课程，尚未完成初始测评。

## 交付包里有什么

| 文件或目录 | 用途 |
| --- | --- |
| `images.tar` | 一次载入前后端、PostgreSQL、Neo4j 和截图录屏工件镜像 |
| `postgres-baseline.dump` | 四个账号和课程学习状态的数据库起点 |
| `media-rag-baseline.tar` | 大数据课程文件与检索索引 |
| `manifest.json` | 镜像 ID、归档大小和 SHA-256 校验值 |
| `demo/` | Compose 文件和启动、恢复、验收、工件提取脚本 |
| `screenshots/` | 从最终应用代码逐步采集的页面截图 |
| `recordings/` | 真实浏览器操作录屏和带讲解的成片 |
| `evidence/` | 构建、测试、截图与录屏的版本和校验记录 |

课程内容来自仓库中的“大数据技术与应用”资料：知识图谱、初测题、作业题库、课件、视频和教材。交付包的应用只监听本机 `127.0.0.1:18080`。

## 现场启动

先启动 Docker Desktop 并确认 Linux 容器引擎可用。将交付目录完整复制到演示电脑，在 PowerShell 中进入该目录，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Restore-Demo.ps1 -BundleDirectory .
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Verify-Demo.ps1
```

恢复脚本先核对归档 SHA-256，再载入镜像、恢复演示项目自己的数据库和课程文件。它只重置 `adaptive-edu-defense-demo` 这个 Compose 项目及其卷。脚本结束后，在浏览器打开 `http://127.0.0.1:18080`。

| 角色 | 用户名 | 密码 | 现场用途 |
| --- | --- | --- | --- |
| 已学习学生 | `student1` | `Test123456` | 展示已有测评、画像、知识图谱、路径、任务和作业反馈 |
| 新学生 | `student2` | `Test123456` | 从只加入课程的状态开始做初始测评 |
| 教师 | `teacher1` | `Test123456` | 展示大数据课程、题库、资源和班级 |
| 管理员 | `admin` | `Admin123456` | 展示账号、课程和班级管理 |

以上密码只用于本机答辩包。现场录屏从登录成功后开始，不展示密码输入过程。

## 建议演示顺序

1. 用 `student1` 登录，确认当前课程是“大数据技术与应用”。在学习中心说明已有学习进度。
2. 打开“学习画像”和“知识图谱”，展示薄弱点、知识点关系和课程资料。
3. 打开“学习路径”，进入一个任务，查看课程资源与任务完成入口。
4. 打开“AI 助手”，搜索并选中“Spark SQL基本操作”知识点，再提问：`Spark SQL 和 DataFrame 有什么关系？`。再查看在线作业和已经生成的反馈报告。
5. 退出并以 `student2` 登录。先展示课程已加入、初始测评尚未开始，再依次完成知识测评、能力评测和习惯问卷，查看测评报告与新学习路径。
6. 以 `teacher1` 登录，展示大数据课程的内容、题库、资源和班级。
7. 以 `admin` 登录，展示系统概览、四个账号、课程和班级。

`student2` 的知识测评包含课程初测题。答题会改变数据库状态；如果需要再次从起点演示，按下一节恢复。

## 演示后恢复起点

关闭正在进行的答题或页面编辑，在交付目录重新执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Restore-Demo.ps1 -BundleDirectory .
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Verify-Demo.ps1
```

验收输出应确认四个账号、唯一的大数据课程、课程内容非空、`student1` 有学习记录且 `student2` 无测评与路径记录。恢复不会改动本机其他 Compose 项目。

## AI 内容与现场网络

准备交付包时，项目内置 AI 已使用 DeepSeek V4.1 Flash 对固定的演示问题和学习流程做真实调用。官方 API 请求名为 `deepseek-flash`。成功得到的回答按模型、调用类型和完整请求指纹保存；现场相同请求可直接使用经过核对的结果。回答文件不含 API key，也不保存原始提问全文。现场运行不依赖外部模型服务；输入与彩排不同的问题时，系统使用课程知识点和资源生成内容，因此答案可能与录屏不同。

镜像中带有 MEFKT-NG 模型包。当前离线 CPU 环境没有内容编码器，掌握度会依据历史答题做统计计算；手册和录屏不把这一步说成已经完成了 MEFKT-NG 推理。

## 截图、录屏和版本核对

`screenshots/` 按操作顺序命名。所有正式截图、原始录屏和讲解版视频都采用 **1920×1080**。`recordings/raw/` 保存各角色的真实浏览器操作，`recordings/` 中另有连贯的讲解版。`evidence/` 记录截图、视频的 SHA-256、采集时运行的容器镜像 ID 和应用代码版本。`manifest.json` 记录镜像与数据库归档的校验值。截图和录屏在同一版应用代码上采集；成片只剪接、配音和添加章节标题，不替换应用画面。

若需要从 Docker 中重新取出这些文件，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\demo\Extract-Artifacts.ps1
```

## 现场快速检查

- `docker compose -f .\demo\compose.yaml -p adaptive-edu-defense-demo ps`：四个运行服务应处于健康状态。
- `http://127.0.0.1:18080/health/`：应返回健康响应。
- 若浏览器显示旧页面，先刷新；仍不一致时核对 `manifest.json` 中的镜像 ID，重新执行恢复脚本。
- 若学生页面不是预期起点，重新执行恢复脚本和验收脚本。
- 不要把本机密钥文件、课程原始资料或演示端口发布到公网。
