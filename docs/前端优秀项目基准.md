# 自适应学习 · 优秀项目设计基准

本基准只吸收成熟产品中已经被验证的任务结构，不复制品牌颜色、插画、动效或页面外观。

## 1. 基准项目

| 项目 | 值得吸收的机制 | 在自适应学习中的落地 | 明确不复制 |
| --- | --- | --- | --- |
| [Khan Academy Mastery](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery-) | 课程、单元和技能三层掌握；活动后明确显示技能升级、下降和推荐练习 | 百分比保留为证据值，同时增加“接触、熟练、掌握”等级；每次作业或检测后展示掌握变化 | 积分化和成就导向的视觉表达 |
| [Duolingo Learning Path](https://blog.duolingo.com/new-duolingo-home-screen-design/?lang=en) | 新内容、复习和故事交错进入单一路径；单元顶部提供 Guidebook | 学习路径交错放置新知识、间隔复习、作业和阶段测试；章节提供“本章指南” | 强游戏化角色、奖励和连续打卡压力 |
| [Open edX Studio](https://docs.openedx.org/en/latest/educators/references/course_development/unit_workflow_and_status.html) | 课程按 section / subsection / unit 组织；区分草稿、已发布、待发布和仅教师可见；支持学员预览 | 教师内容树升级为“章节 / 小节 / 学习单元”；编辑区明确当前草稿和学员可见版本，并提供学员预览 | 复杂的运维术语和过深的后台层级 |
| [Moodle Activity Completion](https://docs.moodle.org/402/en/Activity_completion_settings) | 活动完成由查看、提交、成绩、次数或时长等明确条件决定 | 每个资源、实验、作业和检测直接显示完成条件；教师可批量设置条件 | 让学生手动勾选可以自动验证的完成项 |
| [Neo4j Bloom Perspectives](https://neo4j.com/docs/bloom-user-guide/current/bloom-perspectives/perspective-creation/) | 使用 Perspective 限制业务视角中的节点类别、关系和样式；支持搜索、探索和详情检查 | 图谱提供当前路径、当前章节、薄弱点和全局图四种视角；每个视角只显示相关关系类型 | 数据库标签、Cypher 等技术概念直接暴露给学生 |

## 2. 优化后的核心模型

### 2.1 掌握等级

| 等级 | 证据范围 | 界面含义 |
| --- | --- | --- |
| 未开始 | 无有效证据 | 尚未进入学习路径 |
| 接触 | 1–49% | 已学习但不能稳定完成检测 |
| 熟练 | 50–79% | 能完成常规任务，仍需要复习 |
| 掌握 | 80–100% | 在检测与迁移任务中稳定表现 |

百分比不是奖励分数，而是由题目、实验、资源完成和教师确认形成的证据汇总。等级旁必须显示证据可信度。

### 2.2 学习路径内容类型

```text
章节指南 → 新知识 → 引导练习 → 间隔复习 → 应用作业 → 阶段测试
```

- 路径不再只放知识点。
- 复习节点使用已有知识，但更换情境或题型。
- 作业和阶段测试直接成为路径节点，不再作为侧栏中的孤岛。
- 系统调整顺序时显示变更记录，并允许撤销最近一次自动调整。

### 2.3 活动完成条件

每项活动至少明确一种条件：

- 阅读：到达末尾并完成检查题。
- 视频：观看到 90%，允许拖动但记录有效进度。
- 实验：完成全部步骤并提交运行结果。
- 作业：提交成功；需要及格时同时显示及格线。
- 节点检测：正确率达到 80%。
- 阶段测试：完成全部题目并达到教师配置的标准。

### 2.4 教师发布工作流

```text
编辑草稿 → 发布检查 → 学员预览 → 发布 / 定时发布 → 学员可见
```

教师始终能够看见：当前编辑状态、学员正在看到的版本、发布时间、可见范围和未发布变更。

### 2.5 图谱视角

| 视角 | 默认内容 | 主要任务 |
| --- | --- | --- |
| 当前路径 | 当前节点前后两步、补强分支 | 理解为什么现在学习 |
| 当前章节 | 12–24 个章节节点 | 理解章节结构 |
| 薄弱点 | 薄弱节点、证据和补强资源 | 决定复习什么 |
| 全局图 | 全课程章节聚合，按需展开 | 定位和探索 |

## 3. 优化优先级

### P0

- 学习路径加入指南、复习、作业和阶段测试节点。
- 任务资源显示可验证完成条件。
- 掌握百分比增加等级与证据变化。
- 教师区分保存、发布和学员可见状态。

### P1

- 图谱视角、自然语言搜索和保存当前视图。
- 教师按时间、知识点和掌握等级筛选学生。
- 学员预览支持不同班级和学习状态。

### P2

- 路径调整的对比预览与一键撤销。
- 课程内容版本历史和差异查看。
- 图谱视图分享与教师批注。
