你正在学习 Spark SQL。可以从下面的问题开始，或者直接描述你不理解的地方。

为什么两个看起来一样的 SQL，执行速度会差很多？

S
A

即使 SQL 结果相同，Catalyst 生成的物理计划也可能不同。最常见的差异来自数据分区、连接策略和 shuffle。

  1. 先比较两条 SQL 的 `explain` 输出。
  2. 检查是否出现 Exchange 节点，它通常意味着 shuffle。
  3. 观察 Join 类型；BroadcastHashJoin 往往比 SortMergeJoin 少一次全量交换。
