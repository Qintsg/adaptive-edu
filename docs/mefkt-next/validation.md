# 训练与验证设计

> 本文只定义未来执行方案。本次没有启动训练、下载数据集、拟合校准器或生成实验指标。

## 1. 验证目标

模型是否适合项目，要同时看答题预测、知识诊断、跨课程适用性和教学决策质量。一个整体 AUC 无法替代这些检查。

现有 [v2 结果](../MEFKT_V2_TRAINING_RESULT_20260901.md) 和 [架构说明](../MEFKT_MODEL_ARCHITECTURE.md) 可作为历史背景；其数据、切分和模型格式与新实验不一定一致，不能直接拿记录的数值声称新架构提高或降低了多少。

所有候选与基线必须使用相同可见字段、数据切分和评价样本。公开数据缺少题干、时间或资源事件时，关闭相应能力，不将合成字段作为已观察事实。

## 2. 分阶段拟合计划

| 阶段 | 学什么 | 固定什么 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| A：数据与量尺 | 校验事件、课程目录、参照任务 | 不训练模型 | 去重、时间、来源和切分可审计 |
| B：最小模型 | 内容到题目参数、基础证据状态推断 | 无学习增益，稳定性使用受约束共享先验 | 超过可用统计/IRT 基线，概率不恶化 |
| C：遗忘与跨课程 | 知识类型稳定性、内容和图关系编码 | 不启用个体化的无依据时间参数 | 长间隔及未见课程切分有稳定收益 |
| D：条件增强 | 可靠耗时、个体稳定性、部分得分、Full 上下文 | 每次只增加一个能力 | 对应子集数据足够，消融可复现 |
| E：学习活动转移 | 资源/解析后的受限增益 | 固定已经验证的测量主干 | 存在独立后测和延迟测验 |
| F：校准与策略 | 共享/课程校准、教学阈值 | 冻结基础预测模型 | 独立校准集与策略验证集通过门槛 |

这里只给阶段依赖，不规定必须完成所有阶段。若 B/C 的 Lite 已满足业务需求，就可保留更简单的架构。

## 3. 训练目标

### 3.1 主目标

在每个事件结果可见之前生成预测，再用真实结果计算：

```text
L_response = mean_over_courses(mean_over_valid_events(NLL(y_t, p_core,t)))
L_total = L_response
          + lambda_anchor * L_scale_anchor
          + lambda_shrink * L_parameter_shrinkage
          + lambda_update * L_excessive_update
```

二元题的 NLL 是 BCE；有序评分题是核心档位概率的负对数似然。主干训练与递归更新只使用 `p_core`。阶段 F 在冻结的核心轨迹上拟合独立输出校准器，报告业务 `p_correct` 的指标；校准器不得反向改变状态。课程均衡采样/加权避免大课程吞没小课程，但必须同时报告按真实业务流量加权的指标；少样本课程的估计应报告较宽区间。

量尺约束固定能力—难度的尺度，收缩约束限制课程和知识点小样本参数，更新惩罚防止状态因单次观测剧烈变化。单调性主要由结构保证，不依赖一个可能被其他 loss 抵消的弱惩罚。

证据质量权重决定更新力度，不能让模型通过给所有事件低权重逃避主要预测损失。确有错误标签的记录应按固定审计规则排除，并单独报告数量和原因。

### 3.2 延迟表现与学习转移

有独立后测时，可以额外预测活动后新题的表现；有延迟后测时，可以监督保持情况。每个标签有唯一归属或明确归一化权重，不能作为当前结果、多个窗口目标、资源收益标签被无限重复计数。

资源增益头不能用“模型自己更新前后的 mastery 差值”作真值。学生成绩提升、模型认识修正和模型版本变化要分开分析。

### 3.3 可选辅助任务

可靠逐题耗时足够时可增加对数耗时分布头，但当前真实耗时始终不能进入本次答题预测。偏好、满意度或完播率的辅助任务不得反向强迫能力状态代表“更喜欢这个资源”。

首轮不同时启用大量自监督损失。每个辅助项必须有明确标签、缺失掩码和独立消融证据。

## 4. 数据切分矩阵

| 测试类型 | 切分方式 | 回答的问题 |
| --- | --- | --- |
| 新学生 | 学生完全隔离，测试学生自己的历史按时间累积 | 能否服务未见过的学生 |
| 已知学生未来事件 | 全局时间截断，模型与统计只使用截断前数据 | 能否预测真实未来 |
| 新题目 | 按题目族/模板分组留出，避免改写重复题跨集合 | 是否只记住题目 |
| 新课程零样本 | 完整课程留出，课程校准参数不拟合 | 能否依靠发布时内容和过去测试交互进行推断 |
| 新课程少样本 | 留出课程早期学生用于拟合，后续独立学生/时间用于评价 | 少量校准是否可靠 |
| 新领域 | 完整学科或领域留出 | 内容迁移的实际边界在哪里 |
| 长间隔 | 在上述切分内部按真实时间差分桶 | 遗忘是否有效 |
| 真实业务课程 | 经清理的本课程真实交互留出 | 是否适合大数据课程，而非仅适合公开数学/语言数据 |

所有切分先于构造窗口、计算正确率/平均耗时、拟合难度和归一化参数。题目文本与知识图谱是否在课程发布时可见，应在每种实验协议中明确；测试集结果、事后修订和未来统计始终不可见。

零样本课程接入可以使用发布时已有的课程内容目录；这不意味着可以用该课程最终标签选择模型、校准器或阈值。使用已发布无标签全目录的实验与只给当前候选元数据的严格实验应分别命名。

新学生测试允许用该学生已经发生且已可见的答题结果更新状态，但不反向更新基础模型参数。不得把测试学生未来历史一次性编码进去。

演示账号、合成交互、用于开发的 smoke 数据与真实教学效果评价分开。合成数据适合验证边界条件，不作为教育效果结论。

## 5. 基线与消融

### 5.1 必需基线

- 课程/知识点平滑正确率、最近表现和当前统计回退。
- 简单能力—难度模型，以及不带时间项的知识点状态模型。
- 当前可加载的 MEFKT 在线版本和 v3/Lite；无法兼容时分别标明，不拼接不同指标。
- 新设计 Lite，作为 Full 和各扩展的共同基线。

### 5.2 每项模块都应能被替换

| 消融 | 检查什么 |
| --- | --- |
| 去掉内容，仅使用可用结构属性 | 新课程收益是否来自语义 |
| 去掉关系编码，保留知识点标签 | 图谱是否带来额外价值 |
| 固定稳定性 / 去掉遗忘 | 时间机制是否改善长间隔表现 |
| 全局时间 / 知识点独立时间 | 是否错误把无关练习当成复习 |
| 均值 / 瓶颈聚合 | 多知识点题是否需要不可补偿结构 |
| 等权证据 / 固定质量规则 | 噪声、帮助和重复题处理是否有效 |
| 无熟悉度分支 | 是否将背答案误当成可迁移能力 |
| 无状态方差 / 含状态方差 | 诊断与拒绝自动跳过是否更可靠 |
| Lite / Full | 上下文成本是否有足够收益 |
| 转移关闭 / 开启 | 是否改善独立后测，而非仅提高模型自己给的分数 |

不要求把所有消融做成昂贵的全排列。先做单模块对照，确有交互效应再开展小规模组合实验。

## 6. 评价指标

| 层面 | 主要指标 | 必需分组 |
| --- | --- | --- |
| 二元预测 | NLL、Brier、ROC-AUC；不平衡严重时补充 PR-AUC | 课程、知识点、题型、学生历史长度 |
| 概率可靠性 | 可靠性曲线、分桶校准差、选择性风险 | 未测/稀疏/充分，已见/未见课程 |
| 部分得分 | 档位 NLL、归一化得分 MAE | 评分方式与题型 |
| 诊断 | 独立知识点测验表现、薄弱点识别质量 | 单标签/多标签与冲突证据 |
| 遗忘 | 分间隔 NLL/Brier、未来独立测验表现 | 间隔分桶、时间质量 |
| 路径 | 错误跳过率、补测次数、完成目标所需学习时间 | 先修不足、未测、新课程 |
| 学习效果 | 新题前后测、延迟保持和迁移任务 | 课程、资源类型、起始能力 |
| 工程 | p50/p95 延迟、RSS、GPU 峰值、吞吐、快照大小 | 冷/热缓存、候选数、知识点数 |

ECE 依赖分桶，不能单独作为上线判定。对只有单一类别的组，AUC 标记为不可计算，不用零或一代替。

不确定性的评估重点是“模型称证据不足时是否减少错误决策”。由于没有真实连续掌握度标签，不能仅凭当前正确率声称潜在能力区间具有真实覆盖率。

指标区间按学生或班级等独立单位进行聚类重采样；不能把同一学生的几千条相关事件当作几千个独立样本。新架构的主要比较使用至少 3 个随机种子，并保留预先冻结的测试集。

## 7. 训练之外的结构检查

以下是后续实现必须通过的性质检查，本次仅写设计，不编写或运行模型测试：

1. 翻转当前正确性、替换当前耗时或追加未来事件，当前作答前预测不变。
2. 任一知识点能力单独提高，关联题目概率不下降；题目难度提高，概率不上升。
3. 无学习的时间查询不提高基于均值状态的参照分数、不降低方差；连续查询不消耗或刷新状态。区间上界允许随不确定性扩大而变化。
4. 练习无关知识点不重置目标知识点的遗忘时钟。
5. 同一事件重复投递只更新一次；同题两次真实作答保留两次。
6. 多知识点标签排列、考试题目存储顺序变化不改变结果。
7. 完播、自述学会、资源五星评价不直接提高首版掌握度。
8. 新 ID 可使用内容运行；padding、缺失数据和有效未知题目有不同 mask。
9. 迟到评分不进入更早预测；更正后重建当前状态与按相同可见事件重放一致。
10. 分块处理与连续处理的状态一致；带状态续算时不再次消费重叠上下文。
11. 课程与学生隔离；改名不丢状态，知识点拆分不会无依据复制充分证据。
12. 导出前后、训练核心与在线核心、旧模型回退的字段语义可核对。
13. 改变只读输出校准器仅改变校准概率和参照分数，不改变 `mu/v/s/h` 及后续核心预测轨迹。
14. 两个知识点只有长期共同出现的联合题证据时，即使方差很小，也保持 `joint_only`，不得独立自动跳过。

对于截断反向传播，可以 detach 状态，但不清空历史状态。训练窗口采用“状态续传、不重复消费”或“从指定检查点重放”中的一种，不能同时续传又再次输入已经消费的重叠事件。

## 8. 教学策略的验证边界

首版用可解释规则选诊断、讲解、练习和复习，不直接上线强化学习。

后续若研究行动价值，应记录决策时刻状态、所有合格候选、实际行动、选择概率、成本、完成与后续独立测验。离线策略评价需要历史策略覆盖新策略可能选择的行动；缺少覆盖或可信选择概率时，不能用一个预测头替代可靠评价。双重稳健估计是可研究的方法之一，仍有其适用条件。[离线策略评价方法](https://arxiv.org/abs/1103.4601)

资源效果比较优先使用分组随机或其他有清楚识别假设的试验，控制起始水平和题目难度，关注独立题与延迟结果。只观察“选择某资源的人分数更高”，不能证明资源带来增益。

## 9. 建议的工程验收工作负载

| 配置 | 固定工作负载 | 初始验收预算 |
| --- | --- | --- |
| Lite 热缓存 | batch=1，课程 300 个知识点，候选 100 题，每题最多 8 个标签 | 2 推理线程；一次更新加候选读出 p95 ≤ 100 ms |
| Lite 冷缓存 | 同上，读取持久快照与课程缓存 | 单独报告，不与纯模型延迟混合 |
| Full | 同上，64 条相关历史，分别测 batch=1 与并发批次 | 推理峰值显存 ≤ 8 GiB |
| 大课程 | 3,000/30,000 个知识点，固定局部候选集 | 查询成本主要随候选工作集变化 |

100 ms 是待测的设计目标，不是实测结论。测试时固定硬件、线程、运行时、精度、预热和采样次数；分别报告模型耗时与包含数据库/网络的端到端耗时。参照目录计算可按报告时点缓存，但缓存键必须包含状态与口径版本。

## 10. 上线判定原则

- 实际课程的预测和诊断指标有可重复收益，或在预先约定的不劣范围内显著改善冷启动、延迟或可靠性。
- 使用独立策略验证集选择自动跳过阈值，并报告错误跳过率的上界；旧 `0.85` 阈值不可直接沿用。
- 未测、课程不适用、时间不足、图谱异常和模型不可用时的行为均明确。
- 任一模块若没有可测收益，允许删除或保持关闭。
- 只有随机数、合成数据或公开领域结果时，保持“技术验证”状态，不声称已改善本课程学习效果。

这些门槛需要未来实验和业务样本决定。本设计没有预设“必须达到某个 AUC”来代替与项目需求一致的验证。
