# 模型与数学定义

> 设计提案。本文公式规定一种可实现的近似模型，不是训练结果或对真实认知过程的精确描述。总览见 [README](README.md)。

## 1. 记号与因果顺序

`u` 为学生，`c` 为课程，`k` 为知识点，`q` 为题目，`t` 为事件时间。`K(q)` 是题目确认关联的知识点集合。

一次可信作答的顺序为：

```text
历史状态 B(t-) + 作答前可知的题目条件
    → 预测 p(y_t | history, q_t)
    → 观察结果 y_t
    → 测量校正 B(t|y_t)
    → 在条件成立时加入学习转移
    → 保存 B(t+)
```

当前答案、当前得分、当前耗时和当前反馈内容只能进入后两步。已知题目难度、题型及作答前已明确的测验模式可以进入第一步。

## 2. 课程表示：共享语义，独立寻址

### 2.1 静态编码

题目表示由题干/选项、题型、教师难度、课程与知识点描述构成。资源表示由标题、课程内主题、媒体类型和经过审核的内容摘要构成。文本编码器离线运行，先兼容项目现有 384 维内容缓存；具体编码器不是架构不变量。

```text
x_k = Project(text_embedding(k), category, cognitive_dimension, missing_masks)
g_k = RelationEncoder(x_k, typed_course_edges)
e_q = Fuse(text_embedding(q), question_type, difficulty_prior,
           weighted_pool(g_k for k in K(q)), missing_masks)
```

关系编码最多 2 层，`prerequisite` 保留方向，`part_of/includes` 先统一父子语义，`related` 使用独立参数。无图谱时走内容分支，不伪造先修边。消息聚合归一化，限制高出度节点支配表示。

关系边只参与内容表示和教学准备度计算，不自动将一个知识点的学生状态写入邻居。答对高级知识题可以形成“先修知识值得复测”的线索，不能直接给所有祖先知识点增加成功次数。

### 2.2 多知识点映射

教师/题库确认的 `K(q)` 优先。权重 `w_qk >= 0` 且在集合内求和为 1，默认均匀；有题目分步评分或标注后再学习权重。语义模型猜测的映射须单独保存置信来源，首版不据此写回确定掌握度。

知识点标识仅用于状态寻址，不对应必须重新训练的 embedding 行。课程内状态键使用稳定 UUID，并带课程命名空间；不采用可能碰撞的固定哈希槽混合两个知识点。

没有可信知识点映射的题仍可输出课程先验预测，但标记 `unmapped_item`，不任意写入最近似知识点。

### 2.3 题目参数

```text
b_q = DifficultyHead(e_q)
a_q = min(a_max, a_min + softplus(DiscriminationHead(e_q)))
```

`b_q` 为难度，`a_q > 0` 为区分度。教师的 easy/medium/hard 只是先验，不能当成已校准的数值难度。首版不使用独立题目 ID 记忆分支；大量稳定数据之后可评估带收缩约束的题目难度残差。

训练阶段约束训练参照题难度的中心与尺度，并使区分度处于有限范围，防止能力、难度和区分度任意平移/缩放。绝对尺度由版本化参照目录定义，跨课程不直接比较裸 `mu`。

## 3. 知识状态

每个 `(student, course, concept)` 保存：

| 状态 | 含义 | Lite / Full |
| --- | --- | --- |
| `mu` | 在保存时刻、由证据校正后的能力 logit 均值 | 1 个标量 |
| `v` | 该能力估计的近似方差 | 1 个严格正标量 |
| `s` | 知识可用性衰减的稳定时间尺度，单位小时 | 1 个正标量 |
| `h` | 用于推断后续更新幅度的局部上下文 | 16 / 32 维 |
| `state_time` | `mu/v/s` 对应的状态时刻 | 1 个时间戳 |
| `last_direct_evidence_at` | 最近可信能力观测时间 | 可为空 |
| `effective_evidence` | 去重并分配权重后的直接证据量 | 非负实数 |
| `evidence_status` | 未测、稀疏、已有证据、冲突或不适用 | 枚举 |
| `attribution_status` | 有独立区分证据、仅联合证据或无映射 | 枚举 |

初始化使用共享的弱先验 `mu_0, v_0`，稳定性先验可依赖知识类型。首版固定或强约束先验方差、衰减范围及单步变化上限，避免不确定性分支通过无限增大/缩小方差规避训练目标。

无作答的知识点按需生成虚拟先验，不立即为全课程创建大量状态行。`effective_evidence=0` 必须显示“未测”；一个数值先验不是已掌握或未掌握的判定。虚拟先验在首次有效观测前不依据注册时长衰减，也不生成个体遗忘到期时间。

`h` 不能绕过 `mu` 直接生成最终答题概率。Full 的注意力上下文同样只影响证据更新与稳定性估计，避免表面保留解释变量、实际预测由黑盒旁路完成。

## 4. 连续时间演化

查询必须使用不晚于 `query_time` 的快照；查询过去时点须选择历史快照并按当时可见事件重放，不能直接读取未来状态。对合格快照的知识点计算 `Delta_k = max(0, query_time - state_time_k)`，换算为小时：

```text
mu_k^- = clip(mu_k - ln(2) * Delta_k / s_k, mu_min, mu_max)
v_k^-  = min(v_max, v_k + process_noise_k * Delta_k / s_k)
```

数值域要求 `v >= v_min > 0`、`s >= s_min > 0`、`process_noise >= 0`，并对所有状态检查有限值；多知识点软最小值使用稳定的 `logsumexp` 实现。正下界、裁剪上界及初始先验都属于版本化配置，须在验证集选择，不能针对测试样本修改。

`s_k` 是时间尺度：未触及裁剪时，间隔 `s_k` 会让 `sigmoid(mu)` 对应的赔率减半，**不等于正确率减半**。因此不将它包装成已测得的心理学记忆半衰期。

这一选择使固定参数下的衰减具有可组合性：经过两个时间段与经过总时间相同；纯读取永不重置时钟。查询另一个知识点也不改变本知识点的时间。

当有可信观测到达，先将旧状态演化到该时刻，再校正、保存新的状态及时间。不能仅更新 `state_time` 而保留旧 `mu`，否则会凭空恢复已经衰减的知识。

没有可靠时间的历史仅进行顺序更新，不构造真实小时间隔；输出 `time_quality=unknown`，关闭个体复习到期时间。只有题序不能识别遗忘速度。

首版使用共享/知识类型级稳定性。个体稳定性只有在出现不同间隔下的重复、独立观测后才允许更新，并向共享先验收缩。作为方法依据，时间与可学习稳定性结合已有公开研究；本文衰减公式及系统设计不要求采用其结构。[可训练间隔复习模型](https://aclanthology.org/P16-1174/)

## 5. 作答读出：能力必须经过知识状态

### 5.1 多知识点能力

先计算补偿型均值与用于抑制补偿的软最小值：

```text
A_mean = sum_k(w_qk * mu_k^-)
A_bottleneck = -tau * log(sum_k(w_qk * exp(-mu_k^- / tau)))
A_q = (1 - lambda_q) * A_mean + lambda_q * A_bottleneck
```

`tau > 0`；`lambda_q in [0,1]` 由题目结构属性决定，不读取答案，也不依赖当前能力。首版缺少题型依据时固定 `lambda_q`，比较均值与瓶颈聚合的消融后再决定默认值。

两个聚合对各能力值均单调不减。混合读出能抑制强项补偿短板，但 `lambda_q < 1` 时仍有线性补偿项；只有设为 1 才采用完全的软瓶颈形式。不能将任意混合配置描述为严格不可补偿。

### 5.2 当前题目概率

```text
familiarity_q(t) = bounded_repeat_boost_q * exp(-Delta_q / tau_repeat)
z_q = a_q * (A_q - b_q) + familiarity_q(t)
p_core = sigmoid(z_q)
p_correct = sigmoid(z_q / T_c + beta_c)
```

`p_core` 是状态滤波使用的核心概率；`p_correct` 是对业务输出的只读校准概率。`T_c > 0`、`beta_c` 是课程校准参数，零样本课程使用共享校准值。校准器不参与滤波梯度、学习转移或状态上下文，更新校准器无需重建能力状态，只会改变输出口径。重复熟悉度只根据同题版本的过去曝光生成，非负、有上限，不能写入参照掌握度；首版可设为零。

同题“记住答案”与跨题掌握通过这个有限分支区分。所有未作答题的能力项仍必须来自关联知识点状态。不默认同时学习猜测率、失误率、独立学生能力和任意残差，以免稀疏数据下多组变量相互补偿、难以识别。

Lite 与 Full 的正式分数都采用状态均值处的点预测；这里不是对能力不确定性积分后的概率，不能将 `sigmoid(E[z])` 宣称为严格的 `E[sigmoid(z)]`。能力分布采样仅用于单独展示模型条件分位区间。将概率对增长的方差积分可能破坏遗忘单调性，因此不作为可直接切换的线上读出。

### 5.3 部分得分

有可信评分档位 `Y in {0,...,J}` 时，使用递增阈值 `b_q,1 < ... < b_q,J`：

```text
z_q,j = a_q * (A_q - b_q,j) + familiarity_q
P_core(Y >= j) = sigmoid(z_q,j)
P(Y >= j) = sigmoid(z_q,j / T_c + beta_c)
P(Y = j) = P(Y >= j) - P(Y >= j+1)
expected_score_ratio = sum_j(P(Y >= j)) / J
p_fully_correct = P(Y >= J)
```

边界定义为 `P(Y>=0)=1`、`P(Y>=J+1)=0`，核心分布同理。训练和滤波使用 `P_core` 对应的类别似然，业务使用校准后的分布；同一正温度与偏置保持阈值顺序。得分档位由评分规范提供；任意小数得分不能随意伪装成同一组档位。只有二元标签时使用 `J=1`，不虚构部分得分分布。

## 6. 证据校正：回答“之前的判断该如何修正”

### 6.1 质量权重

每条真实测量事件有 `omega_t in [0,1]`，由评分可信度、题目映射质量、是否已见答案、是否独立作答和来源完整性决定。首版使用有版本的确定性规则，并给出原因。

缺少作答耗时只屏蔽耗时特征，不能默认判为不可信；作答快也不能单独判为猜测。缺少提示信息表示未知，不表示没有提示。LLM 评分只有经课程抽检建立可靠性后才能作为高权重证据。

权重不能仅因模型预测错误而降低，也不能由一个无约束网络学会把难样本权重全部置零。训练中的可靠二元标签仍计入主要预测损失。

### 6.2 可实现的近似滤波

用对角高斯近似知识状态分布。对二元题，设 `j_k` 是核心 logit `z_q` 对 `mu_k^-` 的导数：

```text
gradient_k = (y_t - p_core,t) * j_k
information_k = p_core,t * (1 - p_core,t) * j_k^2
v_k_post = 1 / (1 / v_k^- + omega_t * information_k)
mu_k_post = mu_k^- + clip(omega_t * v_k_post * gradient_k, -delta_max, delta_max)
effective_evidence_k += omega_t * w_qk
```

有序得分头使用对应类别对数似然的梯度和 Fisher 信息近似，仍只有一个题目观测。

一次多知识点作答的有效证据总增量不超过 `omega_t`，不复制为多个独立正确标签。能力梯度依据同一个联合预测计算；没有分步评分时保留归因不确定性。

这里是带步长限制的近似贝叶斯滤波，不是精确后验。多知识点会引入相关性，对角近似可能低估不确定性；验证时必须检查多标签题与稀疏知识点的错误跳过率。Full 后续可在局部 `K(q)` 上保留小型协方差，但不作为首版依赖。

首版增加可执行的归因门禁：长期仅在同一组题中共同出现、缺少能区分各知识点的单独或分步证据时，标记 `attribution_status=joint_only`。即使累计次数多、对角方差很小，也不得单独宣布某个知识点已掌握或自动跳过；只能报告“联合任务表现估计”。获得足够区分性证据且通过诊断门槛后，才解除这个限制。不能用先验、图传播或另一个未经验证的模型输出解除标记。

`evidence_status` 不能仅由方差或作答次数决定。存在近期可靠新题结果持续违背预测、评分来源冲突或映射歧义时，标记 conflicting 并阻止自动跳过；即使近似 Fisher 更新使 `v` 变小，也不能据此宣称冲突已消除。冲突规则在策略验证集上固定，不能针对测试结果临时调整。

### 6.3 行为结果

- 意外答对：向上修正估计；证据不足或可能已见答案时修正较小。
- 意外答错：向下修正；冲突较多时标记需要诊断，不把一次错误等同于全部遗忘。
- 连续重复同题：限制独立证据量，由同题熟悉度解释部分表现。
- 题目映射不清：更新幅度小，优先安排能区分知识点的测验。

## 7. 学习转移：回答“这个事件可能让学生学到了什么”

诊断修正与学习增益必须分开。学生做错后阅读解析，可能使估计先下降、再产生部分学习；不能用一个更新量同时声称解释这两件事。

```text
G_k = learning_enabled * observed_learning_gate
      * gain_max * w_event,k * sigmoid(GainNet(event, h_k, context))
      * (1 - sigmoid(mu_k_post))
mu_k^+ = clip(mu_k_post + G_k, mu_min, mu_max)
v_k^+ = min(v_max, v_k_post + transition_noise * G_k)
s_k^+ = clip(s_k * exp(bounded_stability_update), s_min, s_max)
```

所有学习转移有上限，且单独学习活动不降低估计方差。稳定性更新只在满足时间与证据条件时启用。

| 事件 | 测量校正 | 首版学习增益 | 后续可用的监督 |
| --- | --- | --- | --- |
| 可靠客观题作答 | 是 | 默认关闭，先建立纯证据基线 | 后续独立题/延迟测验 |
| 确认看过解析并完成验证题 | 验证题校正一次 | 经独立回放验证后启用 | 新题表现与延迟保持 |
| 阅读/视频完成 | 否 | 关闭 | 活动后的独立测验 |
| 自述学会了、资源五星评价 | 否 | 关闭 | 只更新偏好和诊断候选 |
| 有过程评分的编程任务 | 可靠评分部分可以 | 视任务和数据验证决定 | 隐藏测试、迁移任务 |

首版保留事件上下文和转移接口，但 `learning_enabled=false`。仅靠答题日志无法稳定区分“原来就会”“刚刚学会”和“评分噪声”；将这几个自由度同时放开并不自动获得可解释性。

启用增益后，门控和 `G` 必须在学习事件真正可见时仅根据当时信息计算。监督它的后测必须先预测、评分，再把该后测结果消费为新证据，不能先用后测修正状态再回头预测同一题。若门控要求“验证题完成”才生效，该验证题仅用于证据校正，此次增益必须由更晚的独立新题监督。

### 7.1 更新上下文的具体结构

```text
event_token = Project(e_q, event_type, result, observed_behavior,
                      missing_masks, core_prediction_error)
context_lite = Pool(最近最多 16 条过去事件的受控统计)
context_full = 2-layer attention(最多 64 条过去相关事件，4 heads)
h_k^+ = GRUCell(Project(w_event,k * event_token, context), h_k)
bounded_stability_update = eligibility_gate * c_s * tanh(StabilityHead(h_k^+))
```

Full 先从当前事件之前的缓存读取上下文，再处理当前已观察结果；不能包含未来事件。同场考试先对事件 token 做顺序无关的加权池化，再对每个知识点更新一次 `h`。选择相关历史依赖课程/知识点标识和过去时间，不访问未来标签。

这里的 GRU 只是小型局部更新单元，不承担全学生历史的唯一知识表示。首版稳定性和学习增益均未启用个体化时，可不计算 `h` 和注意力；Full 只有在阶段 D/E 启用这些条件模块后才有独立意义。

无测量结果的活动取 `mu_post=mu^-`、`v_post=v^-`，且首版 `G=0`；上下文可以记录接触，不能顺带写入一次成功。只有 `eligibility_gate` 表明存在可靠时间和足够分散的直接观测时，才更新个体稳定性。

## 8. 掌握度与不确定性如何输出

### 8.1 参照掌握度

为每个知识点建立固定版本的参照题/评分蓝图 `R_c,k`，覆盖约定难度与题型，优先使用能单独测该知识点的题。定义：

```text
mastery_score_k(t) = weighted_mean(
    expected_score(q, B_u,c(t), familiarity=0) for q in R_c,k
)
```

二元题的 expected_score 就是校准后的答对概率；均使用状态均值处的条件期望，排除熟悉度，不对状态方差积分。参照目录的组成权重固定，不能每次查询用当前题库重新平均。新题加入普通题库不改变指标口径。

这是“在明确参照任务上的预期表现”，不是学生真实掌握知识的百分比。若知识点只出现于高度重叠的多标签题，不能宣称其个体能力已被独立识别。

无合格参照目录时返回潜在能力和 `reference_status=missing`，标准化掌握度为空。可显示“待建立测量依据”，不能悄悄用 `sigmoid(mu)` 冒充已校准掌握度。

目录或只读校准器升级必须记录版本；纵向变化分解为模型/口径变化与新增学习证据，不能全部计作学习进步。更新校准器使参照分数重新计算，但不改变核心滤波状态。

### 8.2 不确定性的三个来源

| 信息 | 解释 | 可以如何使用 |
| --- | --- | --- |
| 答题概率及 `p(1-p)` | 给定模型时的作答随机性 | 选择难度，不作为模型可靠性 |
| 状态方差 `v` | 历史证据对能力估计的约束程度 | 诊断优先级、稀疏标识 |
| 课程适用性/可选模型间分歧 | 新课程与已验证条件的差异 | 降级、拒绝自动跳过 |

可将能力样本映射到参照分数，生成例如 10%–90% 的**模型条件分位区间**。它不包含全部模型偏差，也没有跨课程覆盖率保证；不能标作“真实掌握度的 80% 置信区间”。

概率校准在独立校准集上拟合正温度和偏置，检查 NLL、Brier 与可靠性曲线；概率校准不等于状态区间也已校准。[神经网络概率校准研究](https://proceedings.mlr.press/v70/guo17a.html)

## 9. 先修准备度与教学行动

`prerequisite_readiness` 从先修知识点的证据和参照分数计算，仅用于决策。未知先修返回 unknown；没有先修边返回 not_required。不得通过 `min(parent_mastery)` 覆盖本知识点的直接估计。

教学决策采用“先可行性筛选，再排序”：

1. 筛选课程权限、教师要求、先修风险、时间预算及资源质量。
2. 未测或证据冲突优先诊断；已确认薄弱安排讲解与基础练习；已学但衰减明显安排复习；证据充分且表现稳定安排迁移任务。
3. 诊断题的信息增益可用 `0.5 * sum(log(v_prior / v_after_hypothetical_observation))` 近似，模拟状态不落库。
4. 学习资源按目标相关度、薄弱程度、先修可行性、质量与预计耗时排序。权重作为版本化策略配置，不声称排序分就是学习收益。

实际学习效果需独立前后测与延迟后测。若未来引入行动价值模型，应单独使用动作、候选集合、选择概率和后续结果进行评估，不能把预测概率变大直接解释为因果收益。

## 10. 张量与计算边界

| 对象 | 建议形状 | 说明 |
| --- | --- | --- |
| 事件题目内容 | `[B,L,D_content]` | 未知 ID 也可编码 |
| 事件关联知识点 | `[B,L,K]` + 映射 mask | 与 padding mask 分开 |
| 稀疏状态工作集 | `[B,U,D_state]` | U 为该批涉及的知识点，不是全局词表 |
| 单题读出 | `[B,K] -> [B]` | K 是该题关联知识点数 |
| 候选批 | `[B,C,K] -> [B,C]` | 候选只读，不更新状态 |
| Full 更新上下文 | `[B,M,D]` | M 最多 64，只含过去事件 |

令 `C` 为候选数、`K` 为平均标签数、`D` 为表示维度、`U` 为已观测知识点数。课程表示缓存后，读出主要为 `O(CK)`；局部神经更新约 `O(KD^2)`；状态存储为 `O(U D_state)`。Full 附加注意力约 `O(M^2 D + M D^2)`，只在新事件更新时执行。

以 Lite 的每知识点约 20 个 float32 状态值估算，300 个知识点约 24 KB；Full 的约 36 个浮点值约 43 KB。均未计时间戳、键、证据索引、缓存、序列化与数据库开销，不是服务 RSS 实测。

## 11. 必须保留的性质

- 同题同状态下，提高任意关联能力不能降低预测概率。
- 无新增证据或学习事件、参数固定时，参照掌握度随纯时间推进不增加，状态不确定性不减小。
- 新课程/新知识点增加状态记录，不增加基础模型参数行。
- 一次实际作答只产生一个结果似然；重复投递不重复学习。
- 不可靠资源完成、自述和满意度不创造直接能力证据。
- 图谱邻居可以影响内容与教学建议，不自动获得直接成功证据。
- 所有当前结果先用于更新下一状态，不能用于生成本次作答前预测。
