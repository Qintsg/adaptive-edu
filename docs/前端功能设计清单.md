# 自适应学习 · 前端功能设计清单

产品全称：知识图谱驱动的个性化自适应学习系统

系统简称：自适应学习

本清单以现有前端路由和 API 为边界。每项功能至少明确入口、页面结构、主操作和关键状态；高保真原型优先覆盖学生主闭环。

## 1. 全局功能

| 功能 | 基础设计 | 关键状态 |
| --- | --- | --- |
| 登录 | 简称、用户名、密码、登录按钮；注册链接置于表单底部 | 登录中、账号或密码错误、账号停用、服务不可用 |
| 注册 | 用户名、姓名、密码、确认密码、班级邀请码 | 邀请码校验中、已失效、已使用、注册成功 |
| 角色落点 | 登录后直接进入对应工作台，不在界面解释角色分流规则 | 无权限时进入 403 页面 |
| 当前课程 | 顶栏课程切换器；未选课程时进入课程选择页 | 无课程、课程已关闭、切换失败 |
| 全局搜索 | 搜索知识点、资源、任务；结果按类型分组 | 输入提示、无结果、部分来源失败 |
| 通知 | 截止提醒、教师公告、路径变化、系统通知 | 未读、已读、批量已读、加载失败 |
| 账户菜单 | 个人设置、角色信息、退出登录 | 退出确认、会话过期 |
| 403 / 404 | 说明无法访问的对象，提供返回工作台动作 | 不显示技术堆栈 |

## 2. 学生端

### 2.1 信息架构

```text
今天
  学习工作台
  学习路径
学习
  当前任务
  测评
  作业
  课程资源
  知识图谱
智能支持
  AI 学习助手
  个性化智能体
我的
  课程与班级
  学习画像
  个人设置
```

移动端底部导航固定为“今天、路径、作业、我的”；测评、资源、图谱、AI 与班级从工作台和“我的”进入。

### 2.2 页面与子流程

| 路由 / 功能 | 页面结构 | 主操作 | 必须设计的状态 |
| --- | --- | --- | --- |
| `/student/dashboard` 学习工作台 | 当前轨迹、当前任务、截止事项、最近反馈、紧凑指标 | 继续当前任务 | 未选课程、无路径、任务完成、局部加载失败 |
| `/student/course-select` 课程选择 | 当前课程、可用课程、课程进度和所属班级 | 设为当前课程 | 无可用课程、课程已关闭、切换中 |
| `/student/assessment` 测评中心 | 知识、能力、习惯三项进度和报告入口 | 继续未完成测评 | 未开始、进行中、已完成、需重测 |
| `/student/assessment/knowledge` 知识测评 | 单题答题、进度、暂存、交卷确认 | 下一题 / 提交测评 | 题目加载失败、未答题、提交中、断线恢复 |
| `/student/assessment/ability` 能力评测 | 题目、选项、当前进度、退出暂存 | 下一题 / 提交评测 | 同上 |
| `/student/assessment/habit` 习惯问卷 | 分组量表、说明、完成进度 | 保存并继续 | 未完成项、保存失败 |
| `/student/assessment/report` 测评报告 | 结论、掌握证据、能力维度、习惯偏好、路径变化 | 生成学习路径 | 报告生成中、部分维度缺失、生成失败 |
| `/student/learning-path` 学习路径 | 纵向阶段、当前节点详情、解锁条件、调整记录 | 开始当前节点 | 无路径、生成中、调整确认、全部完成 |
| `/student/task/:nodeId` 任务学习 | 学习目标、资源序列、笔记、节点测验、阶段测试 | 继续下一资源 | 资源暂停、完成失败、跳过确认、阶段测试锁定 |
| `/student/resources` 课程资源 | 资源类型统计、搜索筛选、8–12 项首批列表、关联知识点、来源、进度、推荐原因和学习队列 | 打开资源 | 无资源、无搜索结果、预览失败、下载失败 |
| `/student/knowledge-map` 知识图谱 | 当前章节 12–24 个节点、一跳聚焦、关系筛选、节点详情、掌握证据和关联资源 | 学习选中知识点 | 无图谱、节点无证据、图谱加载失败 |
| `/student/ai-assistant` AI 学习助手 | 当前上下文、对话、课程证据和建议动作 | 发送问题 | 回答生成中、流中断、无课程证据、服务不可用 |
| `/student/agent-learning` 个性化智能体 | 画像补充对话、任务运行时间线、生成资源、应用到路径、效果反馈 | 生成学习包 | 信息不足、生成中、部分失败、应用确认、反馈已提交 |
| `/student/exams` 在线作业 | 待完成、已提交、已批阅三组；截止时间和尝试次数 | 开始 / 继续作业 | 无作业、已过期、可重做、结果待发布 |
| `/student/exam/:examId` 作业答题 | 题目区、答题卡、倒计时、自动保存状态 | 提交作业 | 自动保存失败、时间到、漏答确认、重复提交 |
| `/student/feedback/:reportId` 反馈报告 | 得分、题目复盘、知识薄弱点、建议资源、路径调整 | 加入补强任务 | 报告生成中、无反馈、下载失败 |
| `/student/classes` 我的班级 | 已加入班级、邀请码加入、课程和公告摘要 | 加入班级 | 未加入班级、邀请码无效、重复加入 |
| `/student/classes/:classId` 班级详情 | 公告、作业、成员、学习进度和排名页签 | 查看待办作业 | 无公告、无作业、退出班级确认 |
| `/student/profile` 学习画像 | 掌握结构、能力、习惯、时间趋势、历史版本比较 | 刷新画像 | 首次生成、刷新中、历史为空、导出失败 |
| `/student/settings` 个人设置 | 账户信息、学习偏好、通知、班级加入和安全设置 | 保存更改 | 未保存、保存中、保存失败、已保存 |

### 2.3 学生端跨页面闭环

```text
选课 → 初始测评 → 生成画像 → 生成路径 → 任务学习
  ↑                                      ↓
班级与教师任务 ← 作业与反馈 ← 掌握证据 ← 图谱与资源
                         ↘ AI 助手 / 个性化智能体
```

- 测评、作业、资源和 AI 产生的证据统一回写学习画像。
- 路径发生变化时显示“变化原因、影响节点、撤销或确认”。
- 任何推荐均提供“为什么推荐”，不展示无法解释的排序分数。

## 3. 教师端

教师端以课程工作空间为中心；全局页面只保留教学概览、课程、班级和账户设置。

| 功能 | 基础设计 | 主操作与状态 |
| --- | --- | --- |
| 教学中心 | 待处理事项、风险学生、待批作业、课程健康度 | 处理最高优先级事项；空状态显示“暂无待处理” |
| 课程列表 / 创建 / 编辑 | 课程卡或表格；编辑使用基本信息、封面、开放范围、学习规则 | 创建或保存；未保存、保存中、失败、删除确认 |
| 课程概览 | 学生参与、内容完整度、近期变更 | 发布课程更新；发布前校验缺失项 |
| 知识图谱管理 | 章节树、画布、节点详情；新增、编辑、删除、连线、导入导出 | 保存图谱；冲突、导入校验、发布、索引构建进度 |
| 资源管理 | 上传区、资源表、知识点关联、处理和发布状态 | 上传资源；上传进度、解析失败、关联为空 |
| 题库管理 | 搜索筛选、题目表、题目编辑、知识点关联、批量导入导出 | 创建题目；导入校验、批量删除确认 |
| 作业管理 | 作业列表、组卷、发布范围、截止规则、成绩分析 | 发布作业；草稿、已发布、已截止、撤回确认 |
| 班级列表 / 详情 | 班级信息、课程、学生、邀请、公告、进度 | 创建班级或发布公告；邀请码过期、移除学生确认 |
| 学生画像 | 掌握、路径、作业、活动趋势和教师记录 | 发送反馈；数据不足、反馈成功或失败 |
| 课程设置 | 路径生成、测评、AI、资源发布规则 | 保存设置；未保存、冲突、保存失败 |
| 个人设置 | 账户资料和安全设置 | 保存更改 |

## 4. 管理端

| 路由 / 功能 | 基础设计 | 主操作与状态 |
| --- | --- | --- |
| `/admin/dashboard` 系统概览 | 紧凑 KPI、活动趋势、服务状态、最近审计 | 导出报告；部分统计失败仍保留可用模块 |
| `/admin/users` 用户管理 | 搜索筛选、用户表、详情抽屉、批量操作 | 创建用户；导入校验、重置密码、启停、删除确认 |
| `/admin/courses` 课程管理 | 课程表、教师分配、开放状态和统计抽屉 | 创建课程；教师冲突、删除影响提示 |
| `/admin/classes` 班级管理 | 班级表、教师、学生、课程和统计 | 创建班级；批量加人、移除确认 |
| `/admin/activation-codes` 激活码 | 批次、角色、有效期、使用状态、导出 | 生成激活码；失效、已用、批量删除确认 |
| `/admin/logs` 系统日志 | 时间、操作者、模块、动作、结果筛选；详情抽屉 | 导出日志；清理前显示范围和不可恢复提示 |
| `/admin/settings` 系统设置 | 站点名称、注册策略、功能开关、运行参数 | 保存设置；高风险项二次确认、保存失败 |

## 5. 旧功能优化决策

| 现有设计 | 决策 | 调整后的设计 |
| --- | --- | --- |
| 知识、能力、习惯使用三个并列菜单 | 合并入口 | 侧栏只显示“测评”；内部使用三步流程，支持中断后继续 |
| 课程选择长期占据一级菜单 | 降级入口 | 未选课程时显示完整选择页；已有课程后从顶栏切换 |
| 在线作业、考试、节点测验混用名称 | 统一词汇 | 学生看到“作业”；答题页根据场景标注“课程作业 / 节点检测 / 阶段测试” |
| AI 学习助手和个性化智能体职责不清 | 明确边界 | AI 助手负责问答与解释；智能体负责生成学习包、调整路径和跟踪效果 |
| 课程资源与知识图谱重复展示资源 | 保留两种视角 | 资源页用于搜索与消费；图谱页用于理解关系，两者互相定位 |
| 设置页也提供加入班级 | 删除重复 | 加入班级只在“课程与班级”中出现 |
| 测评报告和学习画像内容重叠 | 区分时间尺度 | 测评报告解释一次测评；学习画像展示长期变化和全部证据 |
| 教师全局侧栏重复列出图谱、资源、题库、作业 | 收拢入口 | 进入课程后在课程工作空间页签管理；全局只保留课程和班级 |
| 管理端首页使用大量欢迎文案和彩色统计卡 | 重构 | 紧凑 KPI、异常、审计和服务状态直接进入治理任务 |
| 反馈报告独立路由与作业标识不一致 | 调整路由计划 | 后续统一为 `/student/assignments/:id/report`，旧地址保留兼容跳转 |

## 6. 新功能计划

| 优先级 | 新功能 | 解决的问题 | 基础设计 |
| --- | --- | --- | --- |
| P0 | 统一待办 | 作业、测评、教师任务和路径任务散落多页 | 工作台按“逾期、今天、本周”展示；可按课程筛选 |
| P0 | 掌握证据账本 | 学生只看到掌握度，无法理解变化来源 | 按时间记录题目、任务、教师反馈和 AI 建议对掌握度的影响 |
| P0 | 路径变更记录 | AI 调整路径后缺少可解释性 | 显示新增、提前、推迟、移除节点及原因；允许撤销最近一次自动调整 |
| P1 | 错题与补强队列 | 作业反馈结束后缺少后续行动 | 错题按知识点聚合，一键生成补强任务并加入路径 |
| P1 | 学习计划日历 | 路径顺序与真实截止日期没有统一视图 | 周视图整合作业、测评、教师任务和自主学习安排 |
| P1 | 学习目标约束 | 路径生成无法表达可用时间和目标日期 | 在智能体中设置每周时间、目标和偏好，调整前预览影响 |
| P1 | 教师干预中心 | 风险学生发现后仍需跨页面处理 | 汇总风险原因、证据、建议动作和反馈记录 |
| P2 | 通知中心 | 当前缺少统一消息阅读状态 | 分类展示公告、截止提醒、路径变化和系统消息 |
| P2 | 离线草稿与恢复 | 答题或长文本输入遇到断线易丢失 | 本机暂存、同步状态和冲突处理 |
| P2 | 数据与隐私 | 学习画像和 AI 使用范围不透明 | 提供数据导出、AI 使用说明和可清除的对话历史 |

P0 进入首轮学生主闭环；P1 在路径、作业和教师工作区稳定后实施；P2 不阻塞首轮改造。

## 7. 页面状态模板

所有功能页面至少使用以下状态之一，不使用只有“暂无数据”的空白卡片。

| 状态 | 设计规则 | 示例文案 |
| --- | --- | --- |
| Loading | 骨架与最终结构一致；按钮禁止重复触发 | “正在加载学习路径” |
| Empty | 说明为空的原因并给出一个下一步 | “完成初始测评后生成学习路径” |
| Error | 指明失败对象，保留其他可用内容 | “课程资源加载失败，重新加载” |
| Disabled | 显示解锁条件 | “完成当前任务后开放阶段测试” |
| Saving | 固定位置显示保存进度 | “保存中” |
| Success | 与触发动作使用同一动词 | “已发布” |
| Partial | 标出缺失模块，不让整页失败 | “画像已更新，历史趋势暂不可用” |
| Destructive | 说明对象、影响范围和不可恢复性 | “删除后 12 份提交记录仍保留” |
| Streaming | 显示生成阶段、停止和重试 | “正在检索课程证据” |
| Offline | 保留草稿并说明同步状态 | “已保存在本机，恢复连接后同步” |

## 8. 内容完整性检查

- 页面有数据时，列表不能只使用 2–3 条占位内容；首批条数按页面类型达到设计方案的密度基线。
- 资源不能只展示标题；必须同时展示类型、知识点、来源、规模或时长、进度和操作。
- 知识节点不能只展示名称；必须提供掌握状态、关系类型、证据、资源和学习意义。
- 图表必须配套精确数值或明细入口，不能成为不可核验的装饰。
- 详情页必须覆盖“这是什么、当前怎样、为什么、影响什么、下一步做什么”。
- 移动端允许折叠和容器内滚动，不允许静默删除关键内容。

## 9. 原型覆盖方式

- 学生端：为工作台、课程、测评、路径、任务、资源、图谱、AI、智能体、作业、班级、画像、设置分别提供可切换页面。
- 教师端：提供课程工作空间、内容工作区和班级工作区，覆盖课程、图谱、资源、题库、作业、学生与设置。
- 管理端：提供系统概览、内容治理和访问审计，覆盖全部七条管理路由。
- 认证端：登录与注册共享同一简洁表单框架。

原型用于确认结构和交互优先级；生产实现仍按组件拆分并接入真实状态。
