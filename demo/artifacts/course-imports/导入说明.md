# Spark 数据处理入门：课程导入说明

1. 登录 `teacher1`，密码为 `Test123456`。
2. 打开“课程管理”，点击“导入建课”。
3. 课程名称填写 `Spark数据处理入门`。
4. 课程描述填写 `学习 Spark 的基本特征、RDD 工作原理和 Spark SQL 数据操作`。
5. 关闭“发布到班级”开关。
6. 上传桌面 `Spark数据处理入门-课程导入包.zip`，直接上传 ZIP 文件。
7. 点击“创建课程”，等待系统完成导入。
8. 在新课程中查看知识图谱、题库、作业和资源列表。
